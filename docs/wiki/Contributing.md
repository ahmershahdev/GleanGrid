# Contributing

The full guide lives in [CONTRIBUTING.md](https://github.com/ahmershahdev/GleanGrid/blob/main/CONTRIBUTING.md). In short:

1. Open or pick an issue (`good first issue`, `help wanted`).
2. Fork → branch from `main` (`feat/…`, `fix/…`, `docs/…`).
3. Change + test; run `vendor/bin/pint`, `php artisan test`, `npm run build`.
4. Open a PR with the template filled in and screenshots in light, dark and mobile.
5. Conventional Commit messages: `feat(checkout): …`, `fix(favorites): …`.

**Translators:** every string exists in all eight files under `resources/js/i18n/` with identical `:placeholders` — see [[Internationalisation]].

**Security issues:** report privately per [SECURITY.md](https://github.com/ahmershahdev/GleanGrid/blob/main/SECURITY.md).

Contributions are released under the MIT licence.
